# 视频复刻初版 · 手机日程

入口：`replica/index.html`。这是独立初版，原有 `index.html` 和 Android 项目未被替换。

## 预览

电脑：<http://127.0.0.1:8765/>

手机与电脑连接同一 Wi-Fi 时，使用电脑的局域网地址和预览服务端口访问。

手机链接依赖当前电脑和预览服务运行，IP 变化后需要重新启动。`serve-phone.py` 只服务白名单内的 7 个网页路径，拒绝访问项目其他文件。重启示例：

```powershell
python serve-phone.py --bind 你的WLAN地址 --port 8766
```

也可直接用浏览器打开 `replica/index.html`。安装到主屏幕和完整离线缓存需要 HTTPS 或 localhost 环境；局域网 HTTP 支持普通网页访问。

## 第一版范围

首次展示的任务和生日为可编辑的示例。当前没有连接系统日历、云账号、天气或真实订阅服务。重复周期和提醒设置已保存为事项属性，尚未实现自动生成周期实例、后台推送或系统闹钟。设置中的在线服务开关保存本机偏好。不同手机的原生日期和时间选择器会略有差异。
