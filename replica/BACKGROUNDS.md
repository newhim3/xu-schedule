# Bundled calendar backgrounds

These are photographs, not generated mountain sketches. They are bundled for offline display with a dark readability overlay. Changing the theme never sends planner data to the image provider.

License: https://unsplash.com/license (retrieved 2026-10-18). This app uses individual photos as UI backgrounds, not a competing image library.
