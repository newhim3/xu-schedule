# 序 · 日程管理

一个手机优先的轻量日程管理应用。它把分类、父类和任务拆开管理，再把所有具体任务按优先级聚合到待办列表中。

## 功能

- 自定义日程分类、父类和任务
- 任务支持四象限优先级与“待设置”状态
- 待办列表按紧急重要 → 紧急不重要 → 不紧急重要 → 不紧急不重要排序
- 本地浏览器存储，支持 JSON 备份导出
- 手机底部导航与桌面侧边导航自适应

## 本地运行

直接用浏览器打开 `index.html` 即可。项目当前为无依赖静态版本，便于后续接入既有的马原刷题软件后端配置。

## 密钥说明

前端不保存或暴露应用密钥。接入后端时，请在服务端通过环境变量沿用马原刷题软件的密钥配置，并将客户端请求指向后端代理。
